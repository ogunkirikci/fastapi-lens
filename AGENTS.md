# Repository Instructions

## Language Policy

English is the only language allowed in this repository.

Use English for:

- Source code identifiers and comments
- Documentation and examples
- User interface text
- API responses, errors, logs, and diagnostics
- Tests and fixtures
- Configuration descriptions
- Commit messages and pull-request content

Do not add Turkish or mixed-language text. A narrowly scoped non-English test
fixture is allowed only when it explicitly verifies Unicode or localization
behavior.
